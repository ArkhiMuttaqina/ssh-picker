# sshpick

`sshp` is a fuzzy SSH host picker for aliases in `~/.ssh/config`. It uses
OpenSSH to resolve each selected host and `fzf` for the interactive menu.

## Install

Review the installer first:

```bash
curl -fsSL https://raw.githubusercontent.com/OWNER/REPO/main/install.sh
```

Then install:

```bash
curl -fsSL https://raw.githubusercontent.com/OWNER/REPO/main/install.sh | bash
```

The installer:

- installs missing `openssh-client` and `fzf` packages using the detected package manager;
- installs `sshpick` into `~/.local/bin`;
- creates `~/.local/bin/sshp` and adds `alias sshp=sshpick` to `.bashrc`;
- adds one idempotent managed PATH block to `~/.profile` and `~/.bashrc`;
- backs up a shell file to `<file>.sshpick.bak` before changing it;
- syntax-checks shell files and restores the backup if validation fails.

For production fleets, pin a release tag instead of mutable `main`:

```bash
curl -fsSL https://raw.githubusercontent.com/OWNER/REPO/v1.0.0/install.sh | bash
```

## Usage

```bash
sshp                  # pick and connect
sshp --list           # list parsed aliases
sshp --preview myhost # show resolved non-secret SSH settings
sshp --config ~/.ssh/work.conf
```

Only concrete aliases are listed. Wildcard and negated `Host` patterns are
excluded.

## Installer options

```text
--bin-dir DIR       custom installation directory
--source-file FILE  install from a local source checkout
--no-path-update    do not touch ~/.profile or ~/.bashrc
--no-install-deps   fail instead of installing missing packages
```

Local checkout install:

```bash
bash install.sh --source-file ./sshpick
```

## Security notes

- Read remote shell scripts before piping them to `bash`.
- Prefer a pinned release tag for repeatable installs.
- The preview is generated by `ssh -G`; it never reads private-key contents.
- This project does not copy SSH config, keys, known hosts, or credentials.
